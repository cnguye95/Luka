# The Turing machine

Alan Turing's 1936 abstract machine: an infinite tape, a head that reads and
writes, and a finite table of rules. It is the definition of computability that
every later model is measured against, and the reason we can say a problem is
undecidable rather than merely unsolved.

The halting problem falls straight out of it. No machine can decide, for every
machine and input, whether that machine ever stops.
